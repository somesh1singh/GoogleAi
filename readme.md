# 🏛️ Forensic Wealth Management & Risk Dashboard App

This is an institutional-grade portfolio risk monitoring dashboard built with Streamlit. It automates financial ledger compilation, audits capital efficiency spreads, and maps multi-timeframe risk corridors natively on your machine with zero external API dependencies.

## 🚀 Local Terminal Deployment Playbook

1. Ensure Python 3.8+ is installed on your local computer.
2. Put `app.py` and `requirements.txt` into the same workspace directory.
3. Open your system terminal or command prompt inside that folder and run:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
